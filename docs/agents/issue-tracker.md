# Issue tracker: Local Markdown

- One feature per directory: `.scratch/<feature>/`.
- Specifications: `spec.md`.
- Tickets: `issues/<NN>-<slug>.md`, numbered from `01`.
- Record triage state in a `Status:` line using `triage-labels.md`.
- Append discussion under `## Comments`.
- Publishing means writing these files; fetching means reading them.
